Política de Privacidade

ProduGuia - Gestor de Guias

Esta política descreve quais dados são utilizados pela extensão, como são armazenados e como são utilizados exclusivamente para o funcionamento do produto.

Resumo

O ProduGuia armazena apenas dados necessários para organizar e restaurar abas. Todas as informações permanecem localmente no navegador e não são enviadas para servidores externos.

Dados utilizados

A extensão pode armazenar localmente:

  • URLs das abas salvas (histórico de navegação utilizado para funcionalidade)
  • títulos das abas
  • nomes das categorias criadas pelo usuário
  • preferências de uso da extensão

Os favicons são obtidos diretamente pelo navegador para exibição visual e não são armazenados separadamente.

Finalidade do uso dos dados

Os dados são utilizados exclusivamente para permitir:

  • salvar e organizar abas em categorias
  • restaurar sessões de navegação
  • exibir informações visuais das abas

Não há qualquer uso para análise, publicidade ou compartilhamento externo.

Armazenamento

Os dados são armazenados localmente utilizando a API de armazenamento do Chrome (chrome.storage.local).

Nenhuma informação é transmitida para servidores externos.

O que a extensão não faz

  • não coleta dados pessoais sensíveis
  • não envia dados para servidores externos
  • não compartilha dados com terceiros
  • não realiza rastreamento ou analytics
  • não utiliza dados para publicidade

Permissões utilizadas

  • tabs: acesso às URLs e títulos das abas para salvamento e restauração
  • storage: armazenamento local dos dados da extensão
  • tabGroups: organização das abas em grupos ao restaurar sessões

Controle do usuário

O usuário tem controle total sobre seus dados, podendo:

  • excluir categorias e abas salvas
  • exportar dados para backup
  • importar ou substituir dados manualmente

Alterações nesta política

Esta política pode ser atualizada para refletir melhorias na extensão ou exigências da Chrome Web Store.
