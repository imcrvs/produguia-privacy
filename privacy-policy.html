Política de Privacidade

ProduGuia - Gestor de guias

Esta política explica de forma objetiva quais dados a extensão utiliza, como eles são armazenados e o que não é feito com suas informações.

Resumo

O ProduGuia armazena apenas os dados necessários para organizar e reabrir abas no navegador. Esses dados ficam salvos localmente no Chrome e não são enviados para servidores externos.

Quais dados a extensão utiliza

A extensão pode armazenar localmente informações como:

  • URLs das abas salvas
  • títulos das abas
  • favicons dos sites
  • nomes das categorias criadas pelo usuário
  • preferências de uso, como modo de abertura, ordenação e tema visual

Como os dados são armazenados

Os dados são armazenados localmente usando os mecanismos de armazenamento disponibilizados pelo navegador Chrome para extensões.

O objetivo desse armazenamento é permitir que o usuário salve, organize, exporte, importe e reabra suas abas e categorias posteriormente.

O que a extensão não faz

  • não envia seus dados para servidores externos
  • não vende, compartilha ou comercializa informações do usuário
  • não coleta senhas, dados bancários ou credenciais
  • não utiliza rastreamento para fins publicitários
  • não injeta scripts remotos em sites

Permissões usadas

A extensão solicita apenas as permissões necessárias para seu funcionamento:

  • tabs: para capturar, salvar e reabrir abas
  • storage: para armazenar categorias, abas e preferências
  • tabGroups: para abrir abas salvas como grupo de abas

Controle do usuário

O usuário pode excluir categorias, remover abas salvas e substituir ou mesclar backups importados diretamente pela interface da extensão.

Alterações nesta política

Esta política pode ser atualizada no futuro para refletir melhorias na extensão ou mudanças nos requisitos de publicação. Quando isso acontecer, esta página será revisada.
